# RADsuite 0.2.11 — local build

RADcast adds **Studio — Treble (recommended)**, using Treble with adaptive protection for faint speech. Ordinary speech stays unblended; flagged quiet passages can recover up to 20% of the original voice.

Each recording calibrates its own presence and leveling. Preservation checks can switch to conservative source cleanup, with a visible warning and retained QA report. WAV and MP3 exports use the guarded Studio path.

Existing project settings and enhancement profiles remain compatible. The full Finnegan render matches the accepted adaptive candidate exactly. This version is installed locally; it has not been published to the public updater.

The earlier method is labelled **Studio — Classic**, removing the ambiguous previous “Recommended” label.
