## Frozen one-model test specification

- Joint ISM DF3 replaces the existing room + DF cleanup block. No WPE, bounded-tail control, second enhancement model or automatic source/HF blend is added in the first trial. Original input is decoded once to 48 kHz float; HP45 remains the existing preparation step.
- Use pinned epoch119 weights, no postfilter, native full-input context and upstream delay compensation. No model-side attenuation limit; report zero explicit inference dry blend. Do not confuse the training dry component with an inference blend.
- Verify every expected checkpoint tensor key/shape and loaded value. Reject any partial/mismatched learned-weight load. Training used 0.5.7pre; cached inference runtime is 0.5.6, so initialization alone is insufficient.
- Use a separate Python environment/cache referencing cached dependencies without modifying them; record versions and source identities. Actual CPU resource use and compatibility remain runtime gates. Verify network denial during inference.
- Compare licensed native-48k natural clean speech and declared synthetic reflections, including clean-input preservation. Then, only if justified by those controls, render Finnegan's full original through the unchanged downstream pause/presence/leveling/compression/mastering configuration. Adaptive gains may differ and are recorded.
- Technical safety checks retain their thresholds. Compare cleanup stems and matched full-context excerpts against B and Adobe. Acceptance requires an audible room-removal improvement over B while preserving the speaker and consonants; it is not certified by metrics alone.

At most one initial listening candidate and one bounded preservation repair in this separate experiment. The app stays on revision 2. No default change, commit or push.
