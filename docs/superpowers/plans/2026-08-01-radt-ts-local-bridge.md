# RADTTS Local Bridge Implementation Plan

> Execute this plan task by task, keeping the red-green-refactor loop for each behaviour.

## Task 1: Add the adapter contract and capability discovery

**Files:** `crates/radsuite-desktop/src/radt_ts.rs`, `crates/radsuite-desktop/src/lib.rs`

- Define serializable capability, request, job, output, and error types for reference-voice synthesis.
- Add pure executable discovery with environment, PATH, and home-directory fallbacks.
- Add exact safe-component, canonical-reference-file, and project-root validation rules.
- Add tests first for discovery ordering and validation failures, observe red, then implement.

## Task 2: Add direct CLI process and job lifecycle

**Files:** `Cargo.toml`, `crates/radsuite-desktop/Cargo.toml`, `crates/radsuite-desktop/src/radt_ts.rs`, `crates/radsuite-desktop/src/state.rs`, `crates/radsuite-desktop/src/commands.rs`

- Add the smallest secure temporary-file dependency needed for exclusive text-file creation.
- Ensure an app-local RADTTS project directory contains the required assets, transcripts, captions, and manifest folders.
- Enforce one active synthesis per project and store child handles/cancellation flags in `DesktopState`.
- Start `radtts synthesize` with direct `tokio::process::Command`, no shell, a secure temporary text file, explicit settings, bounded stdout/stderr readers, and a startup/job timeout.
- On macOS/Linux create a dedicated process group and implement bounded group termination/reaping. Return an explicit unsupported-platform error on Windows until a Job Object adapter is added; do not expose a misleading partial workflow there.
- Map the synchronous CLI to `starting`, indeterminate `running`, `completed`, `failed`, and `cancelled` states without claiming percentage progress.
- Parse the final JSON contract, read `outputs.json`/metadata safely, enforce project/job identity and canonical output containment, and remove temporary files on every path.
- Add deterministic fake-executable tests for success, single-flight rejection, failure, cancellation, timeout, malformed output, Unix descendant cleanup, unsupported-platform handling, and shutdown cleanup.

## Task 3: Wire the Tauri command surface and shutdown hook

**Files:** `apps/desktop-ui/src-tauri/src/main.rs`, `crates/radsuite-desktop/tests/desktop_contracts.rs`

- Register capability, output-list, start, status, and cancel commands.
- Add the Tauri exit/shutdown hook that calls the desktop state's synchronous RADTTS cleanup method.
- Keep all project IDs explicit and preserve the existing fallback-project behaviour.
- Add contract coverage for command request/response shapes and validation errors.

## Task 4: Build the Voice generation workspace

**Files:** `apps/desktop-ui/src/types.ts`, `apps/desktop-ui/src/components/RadtTsWorkspace.svelte`, `apps/desktop-ui/src/App.svelte`, `apps/desktop-ui/src/components/ProjectSidebar.svelte`, `apps/desktop-ui/src/styles.css`

- Add the native workspace using the existing RADcast panel and status patterns.
- Provide script input, reference-file picker, quality, chunk mode, pause controls, output format, indeterminate progress, cancel, playback, and downloads.
- Show captions generated by RADTTS as output downloads; do not offer a misleading captions toggle until the backend supports one.
- Replace the disabled sidebar entry with an active Voice generation route.
- Show missing-runtime and validation states in plain language and identify that reference audio is required for this first release.

## Task 5: Test and integrate

**Files:** `apps/desktop-ui/src/components/RadtTsWorkspace.test.ts`, focused helper tests as needed

- Add focused frontend tests for required fields, disabled states, indeterminate progress, and output state handling.
- Run Rust format, clippy, all workspace tests, frontend tests, Svelte check, style contract, and production build.
- Run a real local capability smoke without downloading a model; gate any synthesis smoke on available model assets.
- Push a ready PR, wait for CI, merge, and fast-forward the canonical `main` checkout.
